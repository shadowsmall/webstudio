WebStudio — documentation

Studio de musique qui fonctionne entièrement dans le navigateur, inspiré de l'ergonomie de FL Studio. Ce guide décrit toutes les fonctions de l'application, fenêtre par fenêtre. Utilisez la recherche à gauche pour trouver rapidement un sujet, ou imprimez la page (Ctrl+P) pour en garder une copie papier ou PDF.

1. Présentation

WebStudio est un séquenceur musical complet : boîte à rythmes pas à pas, synthétiseurs, piano roll, playlist pour arranger un morceau, table de mixage avec effets, automation, MIDI et export audio. Il ne nécessite aucune installation : un double-clic sur index.html suffit.

🥁 Channel Rack

Séquenceur pas à pas, 23 instruments synthétisés, swing.

🎼 Piano roll

Mélodies et accords, gammes, outils de génération et de transformation.

🎞️ Playlist

32 pistes × 160 mesures pour arranger les patterns en morceau.

🎚️ Mixer

Master + 12 inserts, 27 effets, 9 chaînes prêtes à l'emploi.

📈 Automation

Clips qui font évoluer volumes, filtres et effets dans le temps.

💾 Données sur le PC

Sauvegarde automatique dans Documents\WebStudio.

Vocabulaire

TermeSignification
CanalUn instrument du Channel Rack (une ligne de pas).
Pas (step)Une case du séquenceur : 1 pas = 1 double croche (16 pas par mesure).
PatternUne boucle de 1 à 4 mesures contenant les pas et les notes de tous les canaux.
ClipUn pattern (ou une automation) posé dans la playlist.
InsertUne tranche de la table de mixage. Chaque canal est routé vers un insert.
Send (envoi)Copie du signal d'un insert vers un autre (ex. : réverbe partagée).
Mode PAT / SONGPAT joue le pattern sélectionné en boucle ; SONG joue la playlist entière.

2. Démarrage rapide

  1. Ouvrez index.html avec Microsoft Edge ou Google Chrome.
  2. Au premier lancement, le message d'accueil propose de créer le dossier de données : cliquez sur Choisir le dossier, sélectionnez Documents puis acceptez. Le dossier WebStudio est créé automatiquement.
  3. Cliquez une fois dans la page (le navigateur n'autorise le son qu'après une interaction), puis appuyez sur Espace pour lancer la lecture.
  4. Dans le Channel Rack (F6), cliquez sur les pas pour créer un rythme.
  5. Cliquez sur le nom d'un synthé (ex. Synth Lead) puis ouvrez le Piano roll (F7) pour écrire une mélodie.
  6. Dans la Playlist (F5), posez vos patterns, passez en mode SONG (L) et écoutez le morceau.
  7. Exportez en WAV avec Ctrl+R. Le travail, lui, est enregistré tout seul.
AstuceLes lancements suivants affichent une fenêtre « Bon retour » : cliquez sur ▶ Reprendre mon travail pour retrouver votre projet exactement là où vous l'aviez laissé.

4. Channel Rack et séquenceur

Chaque ligne est un canal : LED (mute), bouton de volume, bouton de pan, nom, puis la rangée de pas.

Poser et effacer des pas

ActionRésultat
Clic sur un pasPose une note (glissez pour en poser plusieurs).
Clic droit sur un pasEfface le pas (glissez pour en effacer plusieurs).
Maj + clic droitPose une note douce (vélocité réduite).
Clic sur le nomSélectionne le canal et ouvre ses réglages.
Clic gauche sur la LEDMute / unmute du canal.
Clic droit sur la LEDSolo du canal.

Réglages du pattern

  • Longueur : 1, 2, 3 ou 4 mesures (16 à 64 pas).
  • Swing : retarde les pas pairs pour un groove plus « humain ».
  • + Ajouter un canal : ajoute un instrument (aussi via le menu AJOUTER).

Menu clic droit du nom de canal

Piano roll, fenêtre du canal, renommer (F2), couleur, insérer, remplacer, cloner (Alt+C), supprimer (Alt+Suppr), couper / copier / coller les pas, remplir chaque 2 / 4 / 8 pas, décaler les pas, choisir la piste du mixer, mute, solo, monter / descendre (Alt+↑ / Alt+↓).

AstuceRemplir chaque 4 pas sur un kick crée instantanément un « four on the floor » ; chaque 2 pas sur un hi-hat donne des croches régulières.

5. Instruments et réglages du canal

Les 23 instruments sont entièrement synthétisés : aucun fichier audio n'est nécessaire.

FamilleInstruments
Batterie (11)Kick, Snare, Clap, Hi-hat, Open hat, Tom, Cowbell, Crash, Rimshot, Shaker, Conga
Synthés (11)Synth Bass, Synth Lead, Synth Pad, Synth Pluck, FM Synth, Super Saw, Orgue, 808 Bass, Guitare pluck, Piano électrique, Cordes
Sampler (1)Joue un son importé (fichier audio glissé dans la page ou enregistrement micro).

Les 6 moteurs de synthèse

MoteurPrincipeParamètres spécifiques
SoustractiveDeux oscillateurs mélangés puis filtrés : le son classique des basses et leads.Formes d'onde, désaccord du 2ᵉ oscillateur, filtre (cutoff, résonance), enveloppe.
FMUn oscillateur module la fréquence d'un autre : sons métalliques, cloches, pianos électriques.Ratio, index de modulation, enveloppe de l'index.
Super sawPlusieurs dents de scie désaccordées et étalées en stéréo : son « trance ».Nombre de voix (1 à 9), désaccord, largeur stéréo.
Additive (orgue)Addition d'harmoniques, comme les tirettes d'un orgue.Niveaux : fondamentale, octave, quinte, 2ᵉ octave.
808Sinus grave avec descente de hauteur : basses hip-hop / trap.Glide, saturation.
Corde pincéeModèle physique de corde (type Karplus-Strong) : guitares, harpes.Brillance, tenue.

Volume, hauteur, filtre, enveloppe

Chaque canal a un volume, un pan et une hauteur ; les synthés ajoutent un filtre (cutoff, résonance) et une enveloppe Attack, Decay, Sustain, Release (montée, déclin, niveau tenu, extinction). Volume, pan, hauteur, cutoff et résonance sont automatisables : clic droit sur le bouton › Créer un clip d'automation.

Arpégiateur

L'arpégiateur transforme un accord tenu en suite de notes.

RéglageValeurs
ModeMontant, Descendant, Aller-retour, Aléatoire, Accord répété
Vitesse1/32, 1/16, 1/8, 1/4
Octaves1 à 4
GateDurée de chaque note (court = staccato, long = legato)
ExempleÉcrivez un accord de Synth Pluck sur 1 mesure dans le piano roll, activez l'arpégiateur en mode Montant, vitesse 1/16, 2 octaves : vous obtenez un arpège typique de la musique électronique.

6. Piano roll

Le piano roll édite les notes du canal sélectionné, de C1 à C7. Il est synchronisé avec le séquenceur : les notes apparaissent aussi dans le Channel Rack.

Souris

ActionRésultat
Clic sur une case videCrée une note de la longueur choisie (ou un accord, si un accord est sélectionné).
Glisser une noteLa déplace (hauteur et position).
Glisser le bord droitChange la longueur.
Clic droitSupprime la note.
Bande de vélocité (en bas)Cliquez ou glissez pour régler la force de chaque note.

Barre d'outils

  • Longueur des nouvelles notes : 1/16, 1/8, 1/4, 1/2, 1 mesure.
  • Accord : Majeur, Mineur, 7, Maj7, Min7, Sus4, Quinte : un clic pose l'accord entier.
  • Transposer : ±1 demi-ton, ±12 (une octave).
  • Humaniser : petites variations de vélocité et de position.
  • Vider : efface toutes les notes du canal dans ce pattern.

Gammes

Choisissez une tonique et une gamme : les touches de la gamme sont surlignées pour écrire sans fausse note. Gammes disponibles : Majeur, Mineur, Mineur harmonique, Dorien, Phrygien, Mixolydien, Pentatonique majeure, Pentatonique mineure, Blues.

La playlist compte 32 pistes et 160 mesures. Elle n'est jouée qu'en mode SONG.

Souris

ActionRésultat
Clic dans une pistePose le pattern choisi dans la liste « Pattern à poser ».
Glisser un clipLe déplace.

Clic droit (glisser)Supprime un ou plusieurs clips.
Clic sur la règlePlace la tête de lecture.

Gérer les patterns

Le menu PATTERNS et le clic droit sur le sélecteur de pattern proposent : liste des patterns, premier pattern vide (F4 ; en crée un s'il n'y en a pas), nouveau, cloner, renommer, diviser par canal, vider, supprimer, doubler la longueur (jusqu'à 4 mesures) et remplir une piste libre (pose le pattern sur 8 mesures). Pavé + / Pavé − passent au pattern suivant / précédent.

Méthode conseilléeUn pattern par élément (batterie, basse, mélodie…), une piste de playlist par pattern. L'arrangement devient très lisible et chaque élément s'active ou se coupe indépendamment.

8. Mixer et effets

Le mixer comprend le Master et 12 inserts. Chaque insert possède un fader de volume, un pan, mute, solo, un vumètre, 10 emplacements d'effets et 2 envois (sends) vers un insert de numéro supérieur.

Routage

  • Chaque canal est envoyé vers un insert (clic droit sur le nom du canal › piste du mixer).
  • Ctrl+L lie le canal sélectionné à l'insert sélectionné.
  • Les sends servent aux effets partagés : mettez une Reverb Hall sur l'insert 12 et envoyez-y plusieurs inserts.

Clips d'automation

Un clip d'automation fait varier un paramètre au fil du morceau (ex. : ouverture progressive d'un filtre). Il est joué en mode SONG uniquement.

  • Cibles possibles : volume, pan, hauteur, cutoff et résonance des canaux ; volume et pan des inserts ; tous les paramètres des effets.
  • Création : clic droit sur le bouton › Créer un clip d'automation, ou depuis la fenêtre Automation (F10).
  • Édition : dans la fenêtre Automation, cliquez pour ajouter des points et glissez-les pour dessiner la courbe.

10. Jouer et enregistrer

Clavier de l'ordinateur

Les touches sont lues selon leur position physique (AZERTY et QWERTY fonctionnent pareil) : la rangée du bas à partir de W et la rangée du haut à partir de A jouent deux octaves. ← / → changent d'octave.

Clavier MIDI

Dans Edge ou Chrome, branchez le clavier puis OPTIONS › Activer un clavier MIDI. Les notes jouent le canal sélectionné ; le contrôleur CC7 règle le volume du canal. Avec ● actif pendant la lecture, ce que vous jouez est enregistré dans le pattern.

Micro 🎙

Le bouton 🎙 enregistre le micro ; à l'arrêt, un nouveau canal Sampler contenant l'enregistrement est créé. Autorisez l'accès au micro lorsque le navigateur le demande.

Enregistrer la sortie ⏺

Le bouton ⏺ enregistre tout ce que vous entendez en temps réel dans un fichier .webm ou .ogg (format selon le navigateur) — pratique pour capturer une improvisation.

12. Données et sauvegarde

Vos données sont stockées dans un dossier séparé du programme :

Documents\WebStudio\
  ├─ projet-en-cours.json   sauvegarde automatique à chaque modification
  ├─ samples.json    sons importés (micro, fichiers audio)
  ├─ reglages.json          thème, date de création, dernier lancement
  ├─ Projets\ projets enregistrés (Ctrl+S)
  └─ LISEZ-MOI.txt

Sauvegarde automatique

Chaque modification est écrite dans projet-en-cours.json moins d'une seconde après. Ctrl+Z / Ctrl+Y annulent et rétablissent jusqu'à 100 actions.

La pastille 💾

AffichageSignification
WebStudio ✓Tout est enregistré dans le dossier.
enregistrement…Écriture en cours.
erreur !L'écriture a échoué (dossier déplacé, autorisation retirée…). Cliquez sur la pastille.

Un clic sur la pastille permet d'enregistrer immédiatement, d'ouvrir un projet, de changer ou déconnecter le dossier, et de revoir le message d'accueil.

Projets

  • Ctrl+S enregistre le projet (avec ses sons) dans Projets\.
  • Ctrl+O ou FICHIER › Ouvrir… liste les projets du dossier.
  • FICHIER › Dossier de données… et FICHIER › Message d'accueil donnent accès aux réglages du dossier.

Changer de PC

Copiez le dossier Documents\WebStudio (clé USB, cloud…). Sur l'autre PC, choisissez ce dossier au lancement : tout revient.

Pourquoi l'autorisation est redemandée ?Par sécurité, le navigateur ne garde pas l'accès à un dossier du PC d'une session à l'autre. Un clic sur « Reprendre mon travail » suffit à le rétablir.

17. FAQ et dépannage

Je n'entends aucun son.

Cliquez une fois dans la page : le navigateur bloque le son tant qu'il n'y a pas eu d'interaction. Vérifiez ensuite le bouton Master, les mutes (LED des canaux, mixer) et le volume de Windows.

La pastille affiche « Navigateur seulement ».

Aucun dossier n'est connecté. Cliquez sur la pastille › Choisir un dossier sur le PC… et sélectionnez Documents.

Le dossier n'est plus reconnu.

Cliquez sur 💾 › Changer de dossier… et choisissez Documents\WebStudio : le projet en cours est repris.

Après une mise à jour, rien ne change.

Appuyez sur Ctrl+F5 pour vider le cache du navigateur.

Le micro ne fonctionne pas.

Autorisez le micro dans la barre d'adresse. Si la page est ouverte en file:// et que le micro reste bloqué, lancez un petit serveur local (voir Pour les développeurs).

Le clavier MIDI n'est pas détecté.

Utilisez Edge ou Chrome, branchez le clavier avant d'activer le MIDI, puis OPTIONS › Activer un clavier MIDI.

Mon projet .flp est incomplet.

C'est normal : seuls le tempo, les canaux, les patterns, les notes et la playlist sont importés.

Le son grésille ou saccade.

Retirez des effets lourds (Reverb Hall, Maximus) sur les inserts inutilisés, fermez les autres onglets et baissez les volumes si le Master sature.

J'ai fait une erreur.

Ctrl+Z annule (jusqu'à 100 actions). Les projets enregistrés dans Projets\ ne sont jamais écrasés par la sauvegarde automatique.

18. Pour les développeurs

  • Aucune dépendance ni compilation : HTML, CSS et JavaScript « vanilla » + Web Audio API.
  • État global : l'objet S contient tout le projet (canaux, patterns, clips, inserts, automations, gamme, tempo…) ; SAMPLES contient les sons importés (data URL).
  • Cycle de mise à jour : modifier S → rebuild() (graphe audio) si nécessaire → render…() (interface) → commit() (historique + sauvegarde).
  • Extension par surcharge : chaque module remplace des fonctions globales en conservant l'ancienne version.
const _old = renderMixer;
renderMixer = function () { _old(); /* ajouts du module */ };

Ajouter un effet

Ajoutez une entrée dans FX (nom, valeurs par défaut, paramètres, fonction de construction) : l'effet apparaît automatiquement dans le mixer, les menus et l'automation.

Cache et serveur local

Les fichiers sont chargés avec ?v=7 : augmentez ce numéro dans index.html après une modification. Serveur local facultatif : python -m http.server 8000 dans le dossier webstudio, puis http://localhost:8000. Changer d'adresse (file:// → http://) oblige à rechoisir le dossier de données ; le projet est alors repris.

Format d'un projet

Fichier JSON contenant bpm, channels, patterns, clips, tracks, inserts, autos, scale… Les projets du dossier Projets\ incluent aussi les sons (samples).

19. Limites connues et mentions

  • Pas de plugins VST ni de clips audio dans la playlist (les sons passent par des canaux Sampler).
  • Autorisation du dossier redemandée à chaque lancement (sécurité du navigateur).
  • Firefox et Safari : pas d'écriture dans un dossier du PC ni de MIDI.
  • Gros samples sans dossier connecté : la mémoire du navigateur peut être insuffisante.
